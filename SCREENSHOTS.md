# Screenshot Guide for Store Listings

## Required Screenshots

Both Firefox and Chrome stores require screenshots to showcase your extension. Here's what you need:

### Recommended Screenshot Sizes:
- **Chrome Web Store:** 1280x800 or 640x400 pixels
- **Firefox Add-ons:** 1280x800 pixels recommended

### Screenshots to Take:

1. **Screenshot 1: Basic Zoom (Before/After)**
   - Show a normal image on a website
   - Then show the same image zoomed in with Ctrl visible
   - Annotate: "Hold Ctrl + Scroll to Zoom In"

2. **Screenshot 2: Panning Action**
   - Show a zoomed image being panned
   - Show mouse cursor in "grab" state
   - Annotate: "Click and Drag to Pan Around"

3. **Screenshot 3: Mouse-Centered Zoom**
   - Show zoom centered on a specific part of the image
   - Highlight the mouse cursor position
   - Annotate: "Zoom Centers on Your Cursor"

4. **Screenshot 4: Quality Enhancement**
   - Side-by-side comparison showing image quality
   - Show before/after of zoom rendering
   - Annotate: "Enhanced Image Quality When Zoomed"

5. **Screenshot 5: Works Everywhere** (Optional)
   - Collage showing the extension working on different websites
   - Examples: e-commerce, social media, documentation
   - Annotate: "Works on Any Website"

## How to Create Screenshots:

### Option 1: Manual Screenshots
1. Open a webpage with interesting images (product photos, artwork, etc.)
2. Use your OS screenshot tool:
   - **Windows:** Win + Shift + S
   - **macOS:** Cmd + Shift + 4
   - **Linux:** PrtScn or Shift + PrtScn
3. Load the extension and demonstrate each feature
4. Capture each scenario

### Option 2: Use Browser DevTools
1. Open DevTools (F12)
2. Use the device toolbar to set specific viewport size
3. Take screenshots at exactly 1280x800

### Recommended Tools for Annotation:
- **GIMP** (Free, cross-platform)
- **Photopea** (Free, web-based: https://www.photopea.com/)
- **Canva** (Free plan available)

### Tips:
- Use clean, professional-looking websites for demos
- Choose images with interesting details to zoom into
- Add subtle arrows or highlights to show cursor position
- Use consistent fonts and colors for annotations
- Make sure text is large and readable
- Show the extension in action, not just static images

## Store Listing Images Directory:

Create a `/screenshots` directory with:
```
screenshots/
├── 01-basic-zoom.png
├── 02-panning.png
├── 03-mouse-centered.png
├── 04-quality.png
└── 05-works-everywhere.png (optional)
```

## Quick Test Sites for Screenshots:
- https://unsplash.com/ (High-quality photos)
- https://www.amazon.com/ (Product images)
- Wikipedia articles with detailed diagrams
- Art museums' online collections

Once you have screenshots, you'll upload them during the store submission process.
