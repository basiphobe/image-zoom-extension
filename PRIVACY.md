# Privacy Policy for Image Zoom Extension

**Last Updated:** November 8, 2025

## Data Collection

**Image Zoom does NOT collect, store, or transmit any user data whatsoever.**

## What This Extension Does

Image Zoom is a simple browser extension that allows you to zoom and pan images on web pages using your mouse. It operates entirely within your browser and does not communicate with any external servers.

## Permissions

This extension requires:
- **No special permissions** - It runs as a content script on all websites to provide zoom functionality on any image you encounter.

## Data Processing

- **No personal information is collected**
- **No browsing history is tracked**
- **No analytics or telemetry data is gathered**
- **No cookies are set**
- **No data is sent to external servers**

All functionality runs locally in your browser. The extension only:
1. Detects when you hold Ctrl and scroll over an image
2. Applies visual transformations to the image (zoom and pan)
3. Stores temporary zoom state in memory (cleared when you close the page)

## Third-Party Services

This extension does not use any third-party services, APIs, or analytics tools.

## Changes to This Policy

Any updates to this privacy policy will be reflected in the extension's repository and updated versions.

## Contact

For questions or concerns about privacy, please open an issue on the GitHub repository:
https://github.com/basiphobe/image-zoom-extension

## Your Rights

Since we don't collect any data, there is no data to access, modify, or delete. You can uninstall the extension at any time through your browser's extension management page.
